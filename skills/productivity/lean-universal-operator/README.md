# LEAN UNIVERSAL OPERATOR

A general-purpose efficiency Skill for Claude. It is not tied to any particular project, brand, workflow, or creative universe.

## Installation
1. Extract this ZIP.
2. Keep the folder structure intact.
3. Upload/import the `lean-universal-operator` folder through Claude's Skills interface, where available.
4. Enable the Skill.
5. It can be used alongside specialized Skills; this Skill governs efficiency while specialized Skills govern domain-specific procedures.

## Scope
Writing, research, coding, planning, document analysis, creative work, troubleshooting, and everyday tasks.

## Limitation
This Skill can reduce unnecessary work and verbosity, but cannot remove the token cost of context Claude must process or change account usage limits.
