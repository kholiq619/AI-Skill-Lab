VIDEO KILAT — KHOLIQ

Instalasi:
1. Buka Claude.
2. Masuk ke Customize > Skills.
3. Pilih Create skill / Upload a skill.
4. Unggah ZIP ini, lalu aktifkan skill.
5. Pastikan fitur yang dibutuhkan untuk membuat file diaktifkan pada lingkungan Claude.

Pemakaian:
Ketik /video-kilat diikuti tema atau narasi.
Contoh: /video-kilat Kenapa harga Bitcoin bisa bergerak sangat volatil?

Catatan:
Di Claude.ai, custom Skills tidak selalu muncul sebagai slash command/autocomplete. Jika /video-kilat tidak muncul di menu, kirim teks itu sebagai pesan biasa. Skill ini akan membantu Claude mengenali instruksi jika deskripsinya cocok.

Penting:
Skill mempercepat alur dengan membatasi durasi, jumlah adegan, kompleksitas visual, dan revisi. Skill tidak dapat mempercepat komputasi platform atau menambahkan fitur render/TTS yang tidak tersedia.
