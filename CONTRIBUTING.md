# Contributing

Thank you for your interest in AI Skill Lab.

## Before proposing a change
- Keep each skill focused on one clear purpose.
- Prefer explicit, actionable instructions over vague guidance.
- Avoid unnecessary repetition and oversized context.
- Preserve attribution and respect the terms of any third-party material.
- Do not claim a skill is tested or stable unless it has actually been tested.

## Suggested skill structure

```text
skill-name/
├── SKILL.md
├── README.md
├── examples/
└── references/
```

Not every skill needs every folder. Include only useful supporting material.

## Changes
For substantial changes, open an issue or pull request describing:
1. What the skill is intended to do.
2. What changed.
3. How the change was tested.
4. Any compatibility or usage notes.
