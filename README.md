# AI Skill Lab

**Designing Skills. Engineering Workflows.**

AI Skill Lab is an independent collection of practical AI skills and reusable workflows. The project explores ways to make AI systems more useful through clear instructions, focused capabilities, and repeatable processes.

## Skill collection

### Productivity
- **[Lean Universal Operator](skills/productivity/lean-universal-operator/)** — A general-purpose operating skill focused on proportional analysis, concise execution, and avoiding unnecessary work.

### Content
- **[Narasi Kholiq](skills/content/narasi-kholiq/)** — A specialized skill for developing narration and narrative content.

### Video
- **[Video Kilat Kholiq](skills/video/video-kilat-kholiq/)** — A workflow skill for efficient video production.
- **[Buat Video Kholiq](skills/video/buat-video-kholiq/)** — A skill for guiding video creation and production decisions.

## Repository structure

```text
skills/
```

Each skill directory contains its own `SKILL.md` and supporting documentation or references where applicable.

## Status

These are initial portfolio entries. Skills may be revised as they are tested, documented, and improved. Please check each skill's own documentation before using it.
